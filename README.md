# Caspian Watch

**AI-платформа экологического мониторинга Каспийского моря**
*Каспий теңізінің экологиялық мониторинг платформасы*

Международный хакатон «Caspian Hackathon», 5–12 августа 2026.
Организатор: Управление молодёжной политики Мангистауской области.

---

## Что это

Интерактивная GIS-платформа, которая показывает состояние Каспия по четырём направлениям — вода, загрязнение, живая природа, ресурсы — и сводит их в один экологический индекс.

Главный вопрос, на который отвечает платформа: **где именно море отступает, с какой скоростью и что оно заберёт следующим.**

Ключевые особенности:

- **Каждое число привязано к источнику.** Под каждым графиком и слоем — бейдж со статусом: 🟢 реальные машиночитаемые данные, 🟡 введено из публикации, 🔴 демонстрационные данные. Реестр источников — `data/sources.json`, полностью раскрыт на странице «Методика».
- **Модели, а не чёрный ящик.** Формула каждого расчёта, его источник и ограничения напечатаны на `/methodology`. Отступание берега считается как `Δуровня / уклон дна` — стандартный приём береговой геоморфологии, а не нейросеть.
- **AI не измеряет — измеряет формула.** Тренд, отклонения от нормы, уровень риска и прогноз считаются детерминированно и работают без ключа и без сети. Языковая модель только превращает эти числа в текст через строгую JSON-схему.
- **Работает офлайн.** Все датасеты закоммичены в репозиторий, базовая карта собрана из Natural Earth. При отсутствии сети живые данные (качество воздуха, ветер) подменяются последним снимком с честной пометкой.

## Минимальные системные требования

| Компонент | Требование |
|---|---|
| ОС | Linux, macOS или Windows с Docker |
| Docker | 24.0+ с Docker Compose v2 |
| RAM | 2 ГБ свободно (сборка образа — 4 ГБ) |
| Диск | 2 ГБ |
| Браузер | Chrome / Edge / Firefox / Safari с поддержкой WebGL 2 |
| Интернет | **не требуется** для запуска и демонстрации |

## Запуск — одна команда

```bash
docker compose up
```

Затем открыть **http://localhost:3000**

Первая сборка занимает 3–5 минут (устанавливаются зависимости и собирается production-бандл). Тестовая учётная запись не нужна — платформа полностью публичная, авторизации нет.

### Запуск без Docker

```bash
npm ci
npm run build
npm start          # http://localhost:3000
```

Режим разработки: `npm run dev`

## Основные функции

| Раздел | Что делает |
|---|---|
| **Главная** (`/`) | Скролл-история: анимированная сцена воды, падение уровня, привязанное к прокрутке, морфинг береговой линии 1992 → 2035, структура загрязнения, потери биоразнообразия, сводка анализа |
| **Вода и отступание** (`/map/water`) | Карта с береговой линией по годам, слой обнажённого дна, слайдер лет 1992 → 2035 с воспроизведением, динамика уровня с прогнозом и доверительным интервалом, сток рек, водопотребление стран |
| **Загрязнение и воздух** (`/map/pollution`) | **Живой** AQI по 9 городам (Open-Meteo / CAMS), карта промышленных объектов с радиусом по выбросам, хвостохранилище Кошкар-Ата, структура загрязнения, индекс чистоты воды, слой ветра, **анимация рассеивания шлейфа** по измеренному ветру за сутки назад и прогнозу на сутки вперёд |
| **Флора и фауна** (`/map/life`) | Популяция тюленя как **диапазон** оценок (источники расходятся вчетверо), обвал вылова осетровых с поправкой на браконьерство, сезонность миграции птиц, NDVI побережья, места обитания на карте |
| **Ресурсы** (`/map/resources`) | Запасы нефти и газа, добыча по годам, срок исчерпания, месторождения на карте |
| **Экоиндекс** (`/map/index`) | Сводный индекс 0–100 из пяти компонент, слой открытости экологических данных по странам |
| **Методика** (`/methodology`) | Формула, источник и ограничения каждого расчёта; веса экоиндекса; уклоны дна по секторам; полный реестр источников |

Язык переключается в правом верхнем углу: **қазақша** (по умолчанию) и **русский**.

## Структура проекта

Feature-Sliced Design, адаптированный под App Router:

```
app/                    маршруты и API
  page.tsx              главная — скролл-история
  map/[module]/         пять дашбордов на общей карте
  methodology/          страница «Методика»
  api/data/[dataset]/   отдача датасетов с диска
  api/live/air|wind/    живые данные + офлайн-фолбэк

widgets/                композитные блоки экранов
  hero/                 R3F-сцена воды и первый экран
  story/                скролл-сцены главной (GSAP ScrollTrigger)
  map/                  MapLibre + deck.gl, слои, таймлайн, карточки
  panels/               панели пяти дашбордов
  ai-insight/           карточка анализа
  methodology/          страница методики

features/               пользовательские действия (переключение языка)
entities/               предметные модели
  ai-insight/           JSON-схема анализа и детерминированный расчёт

shared/                 переиспользуемое ядро
  ui/                   GlassCard, MetricCard, AnimatedNumber, SourceBadge…
  lib/                  i18n, анимации, регрессии, правила анализа
  config/               палитра графиков, стиль карты, реестр слоёв
  store/                состояние карты (Zustand)

data/                   все датасеты, закоммичены
  sources.json          реестр источников со статусами
  coastlines/           береговая линия по годам (GeoJSON)
  geo/                  базовая география (Natural Earth)
  snapshots/            офлайн-копии живых данных

scripts/pipeline/       генерация датасетов (в рантайме не участвует)
```

## Обновление данных

Пайплайн запускается разработчиком, результат коммитится. В рантайме платформа его не вызывает.

```bash
npm run pipeline:geo -- <папка-с-natural-earth>   # базовая география
npm run pipeline:data                             # курируемые датасеты + реестр источников
npm run pipeline:coastlines                       # береговая линия по годам из ряда уровня
npm run pipeline:snapshot                         # свежий офлайн-снимок живых данных
ANTHROPIC_API_KEY=… npm run pipeline:ai           # перегенерация текстов анализа
```

`pipeline:ai` — единственный шаг, которому нужен ключ. Без него платформа работает полностью: числа считает `entities/ai-insight/compute.ts`, тексты берутся из `widgets/ai-insight/narratives.ts`.

### Научная основа модели рассеивания

- Pasquill F. (1961) *The estimation of the dispersion of windborne material*, Meteorological Magazine **90**, 33–49 — классы устойчивости
- Turner D.B. (1964) *A diffusion model for an urban area*, J. Applied Meteorology **3**(1), 83–91 — операционная таблица классов
- Briggs G.A. (1973) *Diffusion estimation for small emissions*, ATDL Contribution 79 — коэффициенты σy/σz
- Mardia K.V., Jupp P.E. *Directional Statistics* — круговое стандартное отклонение направления ветра

### Модель искусственного интеллекта

`claude-sonnet-4-6` (Anthropic API) — используется **только офлайн**, в скрипте `scripts/pipeline/gen-insights.ts`, для генерации текстовых формулировок анализа. В рантайме платформа к API не обращается: результаты закоммичены. Числовую часть анализа модель не производит.

## Честные ограничения

Раздел, который обычно прячут. Здесь он вынесен и в README, и на страницу «Методика».

1. **Ряд уровня моря восстановлен**, а не скачан: портал G-REALM был недоступен из сети во время разработки. Восстановление опирается на опубликованные значения альтиметрии и скорости падения; сеть источника доступна — ряд заменяется реальным файлом.
2. **Береговая линия по годам — модель**, а не спутниковое наблюдение: `Δx = Δh / tan(β)` с посекторными уклонами дна. Фактическое измерение требует маски NDWI по Sentinel-2.
3. **Оценки численности тюленя расходятся вчетверо** (от 70 до 300 тысяч). Платформа показывает диапазон, а не одно число.
4. **Официальная статистика вылова осетровых занижена**: незаконный промысел оценивается в 4–10 раз выше законного, что показано на графике отдельной полосой.
5. **Показатель влияния на здоровье — модельная оценка** по методике ВОЗ, а не измерение. Счётчик в реальном времени здесь был бы научно некорректен: такие данные по часам не собираются.
6. **Шлейф выбросов — вероятный сектор переноса, а не измеренное поле.** Высота трубы и подъём шлейфа не учитываются, интенсивность выброса неизвестна, поэтому концентрация только относительная — µg/m³ нигде не приводится. Без данных о ветре анимация не показывается вовсе. Часть координат объектов не имеет подтверждённой точки и помечена в интерфейсе как приблизительная.
7. **Данные Ирана и Туркменистана фактически закрыты.** Это не скрыто, а вынесено в отдельный слой «доступность данных» — ограниченная доступность экологических данных прямо названа проблемой в ТЗ.
